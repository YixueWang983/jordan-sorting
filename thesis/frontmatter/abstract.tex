\addchap{Abstract}
\label{chap:abstract}

Jordan sorting recovers the coordinate order of intersections along a line
from their traversal order on a simple curve. This thesis reconstructs the
1990 Simplified Jordan Sorting procedure as one executable Python core with
ordinary-list and heterogeneous red--black finger-tree backends. The core
maintains its own partial sorted order, upper/lower pair families and sibling
ownership; external input certification supplies the validity precondition,
not the sorted output. Update errors propagate without rollback.

The tree implements stable pair handles, endpoint fingers, local insertion,
split and header-based ownership transfer. A source-level manual argument
checks its physical representation, locality and mixed-operation potentials.
Under unit-cost comparison and machine-word assumptions, with expected lookup
and amortized dictionary growth, it gives linear total work for the valid-input
minimal core. This is not machine verification or an unconditional Python
wall-clock guarantee. Independent model checks, bounded validation and
same-backend replay provide separate execution evidence.

The current matched study qualifies 140 controlled inputs at lengths 32--513
and a separate twelve-input set with two-sided splits. Frozen per-input batch
sizes and twenty paired batches per backend yield 6,080 formal sample batches.
All 66,560 sample calls return correct outputs. Tree/list ratios of input
medians range from 1.114 to 3.535 in the common set (median 2.898), and from
3.147 to 3.213 in the targeted set (median 3.180). The measured tree, with access hooks retained despite disabled detailed
collection, has a higher median on every input; this does not characterize
a hook-free implementation or imply a future crossover. A separate local
diagnostic finds a 37.7--52.1\% median-time reduction on fifteen inputs after
removing field-access hooks. Related constructions and mirrors are not
independent random samples.

The contribution combines an independently recovering implementation,
source-linked representation and cost analysis, and reproducible matched
measurements with explicit timing and evidence boundaries. The earlier
rollback-enabled 60-input study remains separately identified historical
evidence. Recognition and the causal effect of rollback removal are not
measured. The results distinguish theoretical operation costs from the
practical constants of the implemented Python backends.
