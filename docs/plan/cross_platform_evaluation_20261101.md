# Mac / Windows 评测协议补充（2026-11-01）

本补充由作者在 2026-11-01 明确要求支持 Mac 和 Windows、先评估专用 Windows 物理机后制定。新统一执行身份为 `unified_input_suite_run_v2`，环境身份为 `mac_windows_environment_v1`。本文件的 SHA-256 随新统一运行配置绑定。

## 兼容范围及历史边界

当前执行平台为原生 macOS 或 Windows，使用 64 位 CPython 3.12.14、优化级别 0、GC 开启及相同阈值、单个串行测量进程。CPU 不再限定 Apple M4。新的资格、校准与正式采样链必须绑定同一主机、系统版本、解释器、源码、输入和环境；切换主机或源码后不能复用旧校准 B 表。

旧协议、输入追加协议和已封存档案保持原字节。旧 `unified_input_suite_run_v1` 继续按原 Apple M4 环境只读核验，不获得新 Windows 资格。冻结 302 输入及其 8 个排除条目保持原身份；本补充不改变正式排序测量边界、预热数、配对轮数、公共 B 的正式规则、来源预算、截止点或来源执行顺序。

新环境记录主机名、CPU 型号/核心数、内存、系统/架构、解释器及原始电源证据。Mac 解析 `pmset`；Windows 使用 `GetSystemPowerStatus` 与 `powercfg /getactivescheme`，要求交流供电、节能状态关闭，未知状态拒绝。电源计划可为用户选择的固定计划，包括固定 BIOS 频率下的平衡计划；运行前后和每输入前后核对，不擅自更改系统设置。电源检查在排序计时之外。

用户已确认 Sherry02 为专用物理机，BIOS 固定 CPU 5.0 GHz、无其他竞争负载。该声明保存为用户提供的实验条件，与软件实测信息区分，不伪称测得持续恒定频率。不要求关闭系统安全功能。

证据相对路径统一使用 POSIX `/`，生产源码映射不得为空。原始记录先完整写入、flush/fsync 文件并关闭，再在同一目录 replace；POSIX 另外同步目录，Windows 不调用不支持的目录 CRT 操作。保证范围为工作进程终止/超时后的完整记录读取，不宣称突然断电或网络文件系统下的持久性。

## 环境稳定性评估

环境诊断与论文正式采样具有不同身份。诊断用于决定测试服务器，不颁发数学证明或正式实验资格，不生成作者审阅收据，输出 `performance_eligible=false`。正式论文采样仍需要作者真实完成表示、局部性和成本审阅；任何人不得代填已批准的收据。旧“只能由作者在 Mac 执行”的设备限制由本补充替换：作者授权的执行可在受支持 Mac/Windows 上完成，其余真实审阅和前置证据门槛保留。

诊断在开始测量前固定选择：五个来源各取最小 n 和最大 n 中按 case_id 字典序最先的输入，去重后形成 10 输入面板。可显式传入 case_id 运行针对性诊断；比较两台主机时必须使用完全相同的有序输入集合、源码与诊断规则，不能挑选表现较好的输入或轮次。

每个输入先验证 Jordan 合法性及两后端 checked/fresh minimal 输出；单独校准每台主机的公共 B。诊断校准候选为 1,2,4,...,4096，每个后端各三次，选两者批次中位数都达到 10 ms 的首个 B。较大的候选只用于此诊断，正式规则的最大 128 不变。所有计时采用既有 fresh public sorting 的完整边界，预期输出核对、GC collect 和记录写入在计时之外。

默认连续执行三个独立测量会话；每会话每输入每后端预热 5 次，然后 20 轮配对测量，交替先后顺序。使用该主机在测量前得到的同一 B 表，不把校准值或预热值当正式样本。输入顺序按种子 20261101 加会话编号洗牌；会话之间不运行单元测试、分析或开发负载。每个输入任务最多 180 秒，整轮默认 900 秒；任何错误/超时停止，保留已提交记录，不补测或删除异常值。

报告逐输入/后端的中位数、R7 四分位数、IQR/中位数，以及三个会话中位数的 (max-min)/median。后者描述会话间漂移。保留所有原始配对时长和输出，并独立重算。两台主机分别报告，不拼成同一统计样本，也不把两主机差异归因于操作系统本身。

迁移决策依据正确性、完整记录和波动指标。一次 10 输入、三会话的诊断仅提供初步主机选择证据；若 Windows 在两种后端的会话内/会话间指标均更低，可考虑后续在更多日期/输入上确认，再迁移正式分析。速度更快不等于更稳定；没有 Mac 同规则诊断时不得宣称 Windows 已优于 Mac。
