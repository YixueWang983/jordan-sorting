### 1.2 字段、去重与归属

每个来源条目至少记录：

- 全局唯一 case_id、source、original_case_id、source_index、原始文件及其摘要；
- 原样读取的 values、n、原值摘要，以及从小到大映射为 1..n 的完整秩序列及其摘要；
- construction_family、shape、smaller_side_k，以及适用时的 seed、bias、mirror、
  base_id 和 common 嵌套类别；不适用字段明确为 null，不编造来源属性；
- canonical_case_id、duplicate_of，以及独立保存的各阶段执行状态。

**判重使用完整的归一化秩序列，先按摘要查找，再逐项确认。**
seeded 保存的值为 0..n−1，而其他来源多为 1..n；
因此同时保存原值与秩身份，避免仅因整数起点不同重复计时。排序调用使用归属条目的原值。
不同镜像、反向或旋转序列不因结构相关而自动判为重复。

归属优先级固定为：
**common → targeted_split → structural → geometric → seeded**。
同一秩序列只在首次出现的位置拥有计时身份；后续条目标记 DUPLICATE，
链接到该 canonical_case_id，保留来源成员关系，不能再增加一个计时样本。
归属在任何新实验之前冻结；若首个来源后来触发资源退路，也不把其重复条目转移到
另一个来源补测。完全重复的条目共用新版本下的规范输入证据，并核对适用于各条目的
附加谓词；不能借去重跳过结构要求。

阶段二须逐项核对所有 302 个来源条目与原档案/几何 JSON 的值、相对顺序和元数据一致，
并核对 seeded 的排除清单恰为原档案中的 8 个 n=1500 条目；
再发布去重映射、各来源重复数、规范输入数和统一清单摘要。
在此之前不宣称唯一输入数。结果同时报告登记条目数、重复数、归属输入数、
完成资格数和实际正式计时数。

### 1.3 构造族、k 与原 workload 谓词

construction_family 描述输入的生成方法，source 保留证据来源。
targeted_split 与 structural 的 balanced/skew 使用相同的 values_for 参数化构造，
即使旧代码由两个函数实现，也标为同一构造族。具体字段约定如下：

| 来源及 shape | construction_family | smaller_side_k |
|---|---|---|
| targeted_split / targeted | values_for | 3、7、19，来自原参数 k |
| structural / balanced | values_for | n=128/129 时为 30；256/257 时为 62；512/513 时为 126 |
| structural / skew | values_for | 1 |
| structural / repeated | repeated | null；每次 split 的实际较小侧另存完整分布 |
| common | 按旧选择元数据区分递增平坦、低/中嵌套块构造及嵌套后缀 | null |
| geometric | grid_tree_corridor_polygon | null |
| seeded | seeded_legal_gap | null |

smaller_side_k 是指定构造的输入参数，不将多次 split 的均值、最大值等冒充单个 k。
资格 trace 中的实际较小侧值另存为事件列表，并核对 values_for 条目的参数。
所有来源均完成一般合法性、正确性和状态核对，另外保留以下既有谓词：

- targeted_split：两后端各自的 primary checked trace 必须出现实际执行、两侧非空、
  且 min(left_size, right_size) 等于指定 k 的 split。
- structural：保留
  [require_structural_coverage](../../experiments/structural_split_protocol.py)
  的原条件。令 e = n − (n mod 2)、m = (e − 6)/2。
  balanced/skew 恰有一次双侧 split，其 owner 为有限 pair，源列表大小为 m，
  较小侧分别为 floor(m/2) 和 1。
  repeated 恰有 floor((e−4)/8) 次双侧 split，均为有限 owner，
  对先前 split 输出再次切分的次数至少为该次数减一。
- 继续保存原结构覆盖的源/输出大小、owner、直接后续插入和再次切分信息。
  不额外要求两个输出都被更新，也不把直接更新记录解释为完整后代历史。
  geometric 和 seeded 不新增基于 split 个数、较小侧或性能结果的逐例纳入门槛。

1. **等价性验证。** 在全部规范输入上重新核对插桩/无插桩树的 checked 输出、
   完整逻辑 trace、各完成前缀状态及审计，以及 fresh minimal 输出。
   保留原固定 targeted 条目的详细计数对照。既有历史 trace 作为回归参照保留，
   新增来源按可用旧记录的实际覆盖核对，不能声称旧 192 输入档案已覆盖本轮 302 个条目。
   沿用既有等价性工具的每输入 600 秒、整轮 7200 秒预算及失败保留规则。
2. **Qualification。** 对 ordinary_list 和 heterogeneous_finger_uninstrumented
   执行 synchronous qualification：双 checked 实例在每个完成前缀比较并审计、
   第三个 fresh checked replay，以及 fresh minimal call。
   保留 oracle 认证、实际输出和附加 workload 检查，再独立验证资格档案。
3. **逐输入校准。** 每个规范输入分别选择一个供两后端共用的 B；不按来源共享一个 B，
   不按比值调整 B。资格及校准均在来源边界记录完成状态和资源预算。
4. **正式采样。** 所有可计时来源的前置工作和源身份核对完成后，
   由作者按原协议完成本人审阅和 receipt，并在 Mac 上执行第 4 节的连续会话。
   本追加不代填批准，也不改变本人执行的原要求。
5. **独立验证与分析。** 采样会话结束后，从原始记录重建输入、调度、配置、输出及统计，
   核对两套重建结果。分析程序不能只读取运行程序的汇总作为验证。
   原始记录和未完成状态均保存；分析不会触发排序或补采样。

资源退路仅处理第 3 节明确允许的准备阶段超时/截止未完成。
等价性不通过、输出或 trace 不一致、档案损坏、源码或环境不符等不属于资源退路；
须停止相关执行、保存失败并调查，不能把错误输入排除后继续宣称全套正确。

## 5. 核心指标、结构描述与图表

### 5.1 统计单位与整体概述

对每个实际完成正式计时的规范输入 i，定义：

r_i = median(tree 的 20 个 elapsed_ns/B) / median(list 的 20 个 elapsed_ns/B)。

r_i < 1 表示树更快，r_i > 1 表示列表更快；判定使用未四舍五入的值，
r_i = 1 单独计数。一个规范输入贡献一个比值，不把 B 次调用或二十个 batch
当成二十个独立输入。

整体首先报告“实际计时的 N 个唯一输入中树更快 X 个”，并列出每个来源的
实际计时数和更快数；若有重复或未完成，不使用 302 作为性能计数分母。
全部比值的中位数及范围保留为**次要的描述性汇总**，注明各来源组成及每输入等权。
不把这个混合构造集合的中位数当作主要结论或真实应用分布的总体加速比。
摘要优先使用有分母的计数式概述，并交代缺失来源。

### 5.2 按来源及类别报告

五个来源分别报告登记数、重复数、规范输入数、完成资格数、正式计时数，
以及 tree/list 比值中位数、最小值、最大值和树更快的输入数。
common 内继续按原四种嵌套类别分层，必要时同时按 n 展示。
structural 保留 balanced、skew、repeated 的 shape；
values_for 的联合图不改变 targeted_split 与 structural 的来源归属。

每来源从新资格记录的每输入、每后端 **primary checked trace** 重建：

- split 总数 S_i：performed=true 的 split 事件数；
- 双侧 split 数 I_i：上述事件中 left_size>0 且 right_size>0 的数量；
- 每次双侧 split 的 min(left_size,right_size)，完整频数分布及最小值、中位数、
  最大值，单位为 sibling list 中的 pair 条目；
- 含至少一次双侧 split 的输入数，以及每输入比例 p_i=I_i/S_i。
  S_i=0 时 p_i 为 NA，不把 0/0 填成零；该类输入另计数。

两后端的逻辑结构逐项核对；一致时可展示一份表并说明一致性。
同步 peer、fresh replay、两后端和重复条目不重复增加结构样本数。
没有双侧 split 时，较小侧分布为空、摘要为 NA；部分资格记录仅按实际完整输入
提供描述，另列中断输入，不冒充全组覆盖。
资格结构表和性能表若完成范围不同，明确列出各自分母；
涉及比值与结构的联合图只使用两类证据均齐全的同一输入。
保留重复条目的来源映射，但主要来源结构汇总按规范归属计数，避免重复累计事件。
