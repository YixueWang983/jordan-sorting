\addchap{Abstract}
\label{chap:abstract}

Jordan sorting recovers the coordinate order of intersections along a line
from their traversal order on a simple curve. This thesis reconstructs the
1990 Simplified Jordan Sorting procedure in a shared Python core with
ordinary-list and heterogeneous red--black finger-tree backends. The core
maintains its own partial sorted order, upper/lower pair families and sibling
ownership. Input validity is certified externally; the core computes the
sorted output itself.

The tree implements stable pair handles, endpoint fingers, local insertion,
split and header-based ownership transfer. A manual source-level argument
checks the physical representation, locality and mixed-operation potentials.
For the valid-input minimal core, it gives linear total work under unit-cost
comparison and machine-word assumptions, with expected dictionary lookup and
amortized dictionary growth. Independent model checks, bounded validation and
same-backend replay test the implementation.

The current matched study qualifies 140 controlled inputs at lengths 32--513
and a separate twelve-input set with two-sided splits. The protocol fixes
per-input batch sizes and collects twenty paired batches per backend, yielding
6,080 formal sample batches. All 66,560 sample calls return correct outputs.
Tree/list ratios of input median runtimes range from 1.114 to 3.535 in the common
set (median 2.898), and from 3.147 to 3.213 in the targeted set (median 3.180).
The measured tree retains access hooks with detailed collection disabled and
has a higher median runtime on every input. A separate local diagnostic finds
a 37.7--52.1\% reduction in median runtime on fifteen
inputs after removing field-access hooks. Four of fifteen cases favor the
hook-free tree, while eleven still take 1.09--1.68 times the list time.

The thesis connects the reconstructed algorithm to its implementation and cost
argument, and provides reproducible matched measurements of both backends.
For the measured Python configuration, the tree's stronger structural bound
coexists with higher runtime over the tested inputs.
