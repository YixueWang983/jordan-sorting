\addchap{Abstract}
\label{chap:abstract}

Jordan sorting asks for the order of the intersection points of a simple
curve and a line along the line, given their order along the curve.
Hoffmann et al.\ (1986) and Fung et al.\ (1990) showed that this can be done
in linear time when the underlying dynamic lists support the required
finger-search operations and cost bounds. This thesis presents an executable
Python reconstruction of the 1990 simplified algorithm. A single sorting
procedure runs on two interchangeable backends: ordinary Python lists and a
heterogeneous red--black finger tree. For the tree backend, a manual amortized
analysis gives linear total work on valid inputs under unit-cost comparison
and machine-word assumptions, with expected dictionary lookup and amortized
growth.

In a paired experiment on \UnifiedN{} fixed inputs of lengths
\UnifiedMinN{}--\UnifiedMaxN{} from \UnifiedFamilyCount{} input families,
the tree backend, timed without the instrumentation used for operation
counting, was faster on \UnifiedWins{} inputs and the list backend on the
remaining \UnifiedListWins{}; the median tree/list ratio was \UnifiedMedian{}
(range \UnifiedMinimum{}--\UnifiedMaximum{}). The median ratio fell from
\UnifiedSmallBandMedian{} for lengths \UnifiedSmallBand{} to
\UnifiedLargeBandMedian{} for \UnifiedLargeBand{}, and the tree's largest
advantages occurred on heavily nested inputs that require almost no
splitting. The results describe these input families on one machine;
the experiment does not isolate the cost of individual operations.
