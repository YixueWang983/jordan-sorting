\section{Supplementary Reviewer Material}
\label{sec:appendix-external-review}

Four files received on October 20 are preserved verbatim in
\nolinkurl{validation/thesis_revision_20261020/external_review/}.
They report 1,900 stress inputs and fifteen-input wrapper medians, but lack
bound command lines, source/environment identities and individual records.
The original scripts have no optimization guard; the timing script checks only
the last output per batch. These external aggregates are excluded from verified
coverage and formal estimates; their arithmetic and limitations are archived.

The separate \nolinkurl{local_supplement/} fixes protocol, source hashes and
inputs before execution. Its adapted runner guards optimization, checks every
timed output, saves all 900 diagnostic batches and preserves traces for forty
bounded correctness inputs. This is not a reproduction of all external runs
or a formal campaign. Shared Python files match \texttt{19a553fb}; each
diagnostic process records its runtime monkeypatches. Seeded generation is
not uniform population sampling.
