\chapter{Conclusion}
\label{chap:conclusion}
\label{sec:conclusion-summary}

This thesis reconstructs Simplified Jordan Sorting as one executable core with
ordinary-list and heterogeneous finger-tree backends. Both recover the sorted
output from their maintained state. The implementation connects the paper's
operations to a source-level cost argument and a reproducible runtime comparison.

\section{Answers to the Research Questions}
\label{sec:conclusion-questions}
\label{sec:conclusion-rq1}

\textbf{RQ1: reconstruction and correctness.}
The shared Step~1/2/3 loop maintains geometric ownership, exact sibling groups
and sorted prefixes. The argument in \cref{app:backend-argument} explains the
two odd-stage $z_1$ corrections, temporary transfer, reversed ribs and recursive
repair transients. Stable pair identities and child groups survive splitting.
The two predetermined input sets passed qualification; all 66,560 formal sample
calls and 1,520 warm-ups returned correct outputs.

\label{sec:conclusion-rq2}
\textbf{RQ2: observed runtime.}
For the measured configuration retaining instrumentation hooks, every input has a
higher tree median runtime. Common-set tree/list ratios have median 2.898 and range
1.114--3.535; the targeted set has median 3.180 and range 3.147--3.213.
These are ratios of twenty-batch input medians for the measured implementations,
including their wrapping, checking and allocation costs. A separate
fifteen-input supplementary diagnostic reduces tree medians by 37.7--52.1\% when instrumentation
hooks are removed. Four of fifteen cases, the large heavy constructions,
favor the hook-free tree; the remaining eleven take 1.09--1.68 times the
list time.

\label{sec:conclusion-rq3}
\textbf{RQ3: structure and cost.}
One potential pays propagation across mixed updates, giving amortized constant
endpoint insertion and smaller-side logarithmic split. A list-size potential
then pays the split terms over the full run, including bounded ownership and
shared-core work. The linear total uses unit-cost comparisons and machine-word
operations, expected dictionary lookup and amortized growth. Ordinary-list
insertion copying alone has a quadratic lower bound.

The common workload has no two-sided splits; the targeted group contains one
per input with source size 61 and smaller sides 3/7/19. The measurements thus
cover different operation mixes within complete sorting calls. The practical
slowdown of the measured Python configuration is compatible with the structural
bound.

\section{Contributions and Further Work}
\label{sec:conclusion-contributions}
\label{sec:conclusion-future-work}
\label{sec:conclusion-closing}

The thesis provides an implementation whose operations can be traced to the
reconstruction and cost argument, together with reproducible measurements.
Independent review of the finite-parent locality extension and mixed-operation
proof would strengthen confidence in the argument. The next empirical step is
to qualify a production hook-free configuration and test broader split
histories and environments under predeclared rules. The supplementary diagnostic
and 40-input seeded correctness supplement provide starting points, while the
existing data remain available for comparison. Recognition, invalid-input
behavior, error correction and geometric applications would each require
their own specification and evaluation.
