# 全文语言修订记录 — 2026-10-31

本轮按作者要求使用 Academic Humanizer，对摘要、八章正文、证明附录、证据与 AI 使用附录及其反思部分进行了语言修订。重点是减少重复的证据边界提醒，让研究问题、方法、结果和结论衔接得更直接。修改范围为 12 个 TeX 文件。

## 主要修改

| 部分 | 修改内容 |
| --- | --- |
| 摘要与引言 | 保留输入前提、复杂度假设、被测配置和主要结果；删去反复出现的机器验证、未来交叉点、历史 rollback 因果效应等提醒。摘要末尾转为说明实现、分析和测量之间的联系。 |
| 背景 | 精简“本研究不声称什么”的段落，集中介绍几何结构、已有算法和两种实现的选择依据。保留全部文献引用。 |
| 算法重建 | 保留源论文规则、对称重建和可执行澄清的分类；保留全部算法步骤、反例、公式及失败语义；合并对解释唯一性和输出来源的重复提醒。 |
| 实现 | 简化版本说明、正确性检查和观测成本的重复限定。明确字典查找的期望成本、同一核心重放的作用，以及逻辑计数与计时的区别。 |
| 实验方法 | 将批次统计单位、构造输入的依赖关系放在统计汇总部分；保留校准、计时范围、固定输入与版本绑定的完整说明。 |
| 结果 | 直接呈现正确输出、运行时间、结构分组和插桩诊断。图表说明更简洁；关键统计量定义和诊断协议继续保留。 |
| 局限性 | 集中说明模型假设、输入覆盖、插桩配置、统计解释及外推限制；将章节末尾重复的否定清单改为对后续实验条件的说明。 |
| 结论 | 围绕三个研究问题给出回答，精简重复免责声明；保留复杂度假设、实测配置、数值结果和后续研究方向。 |
| 附录 | 证明附录只修改开头和结尾的说明文字。反思部分保留作者的经历、判断和责任表述，调整重复措辞；AI 使用记录补充本次语言修订。 |
