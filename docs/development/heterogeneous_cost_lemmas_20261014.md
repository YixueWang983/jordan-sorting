## 1. 黑高的基准与单次向下 join

记 `r(T)=T.root.rank`，外部黑叶的 rank 为零；定义

\[
\nu(T)=r(T)+[T\text{ 的根为红色}].
\]

这是根黑化后的 rank，不是原始 rank。`join_down` 首先对两个非空输入调用
`color_rank(root, False)`。令这之后的 rank 为 `a,b`，结果为 `c`，则局部
`combine/balance_down` 的契约给出

\[
\max(a,b)\le c\le\max(a,b)+1,
\qquad Q\le2|a-b|+3,
\]

其中 `Q` 是实际 `combine` 调用数。下降只在较高的一边进行，每经过一个黑节点
rank 差减一；红节点不能连续出现。同 rank 的黑根是基例，回溯每层只做常数次
`balance_down/refresh_down`。四种红红修复的返回根是红色、两个孩子黑色；
不修复时保留该层 rank。因此最终黑化至多再加一。若结果严格高于
`max(a,b)`，结果根必为黑色且有两个黑孩子。

相对于**黑化前**的输入，安全表述是至多增加二，而非一。实际反例：两个各含
两片叶的红根组件，原 rank 都为 `0`，黑化后都是 `1`，拼接后的黑根 rank 是
`2`。新增测试使用真实节点复现，不是修改计数器模拟该现象。

空输入分支只退役 connector 并返回另一侧，不执行根黑化；后面的推导对这种
返回使用 `ν`，不能误当作已经黑化。

## 2. split_down 的相邻 join 怎样累计

需要比“每次 join 加一”更强的归纳性质。对原 rank 为 `r` 的合法组件执行
`split_down`，每个非空输出满足：

1. 规范化 rank `ν ≤ r+1`。
2. 若原组件根黑，且输出达到 `ν=r+1`，该输出根黑且两个孩子均黑。

**归纳。** 叶子直接成立。设两个原孩子的 raw rank 为 `q`。

- 原根黑时 `r=q+1`。递归输出与未动兄弟的规范化 rank 均至多 `q+1`，
  join 的结果至多 `q+2=r+1`。达到 `r+1` 必须触发上一节的增高情形，
  因而两个孩子均黑。未参加 join 的输出至多 `q+1`。
- 原根红时 `r=q`，两个原孩子均黑。若递归结果规范化 rank 至多 `q`，
  与 rank 为 `q` 的兄弟 join 后至多 `q+1`。若递归结果达到 `q+1`，
  对原黑孩子使用第 2 条，知其根及两个孩子皆黑。此时与黑高 `q` 的兄弟
  join 只下降一层；新红 connector 接在黑根下，不形成红红，结果仍为
  `q+1`，不会再升为 `q+2`。另一输出也符合界。
- 空侧 join 不增高，退役 connector；同样满足上述两条。

在一次回溯 join 中，设累计输出的规范化 rank 为 `a`，原未动兄弟为 `b`。
由归纳性质 `a≤q+1`，而 `b≥q`，所以 **`a-b≤1`**。
结果 rank `c≥max(a,b)`，单次真实递归调用数因此满足

\[
Q\le2|a-b|+3\le2(c-a)+5.
\]

左右输出分别是一条 rank 不下降的累计序列。将两边分别求和后，`c-a`
望远镜抵消；空侧返回可能使累计 rank 上升，但没有相应的昂贵 join，
只会使上界更宽松。若非空 join 数为 `J`，总调用数有界于

\[
\sum Q\le2(\nu(L)+\nu(R))+5J.
\]

原搜索路径、空侧 connector 退役和所有 frame 的维护均为 `O(H)`，两个最终
输出 rank 也为 `O(H)`。因此 **`split_down` 的全部 join 为 `O(H)`，
无需逐次支付 `O(H)` 得到 `O(H²)`**。空间仍为 `O(H)`。

本轮枚举 1–10 片叶的所有有序红黑着色形状（包括红根）及每个切分位置，
独立重算输出顺序、rank、span、分隔键及红黑性质，并检查上述不等式。
这是归纳论证的有界反例搜索，不是归纳论证本身。

## 3. 另一 rib 行走只在哪些位置发生

`repair_short` 处理的是一条外侧 rib 的黑高短缺。

- `parent` 非根时，`_inner(parent)` 是 `INTERIOR` 子树，兄弟的两个孩子
  都是向下指针，`sibling_children` 不调用 `rib_child`。
- `parent` 是根时，兄弟是另一条全局 rib 的顶节点，才需要反向寻找其 far
  child。此后若传播，`short=parent` 已到根，循环结束；若是红兄弟旋转，
  新的 parent 变为非根，后续兄弟是内部子树；若是 near 旋转，至多再取一次
  新顶节点的 far child，随后 far 旋转返回。

因此一次 `repair_short` **至多两次** `rib_child`，每次目标均为当前根的
直接孩子。不存在“每个传播层都遍历另一条 rib”的二重循环。

设初始 short rank 为 `r0`，传播次数为 `D`。传播到祖先每步至多升一 rank，
根附近终止旋转只增加常数层，故发生行走时的根 rank 至多 `r0+D+2`。
无相邻红节点给出路径长度的两倍黑高界。两次行走总计可用
`4(r0+D+2)` 的宽松界支付，其余修复工作是 `O(D+1)`。
本轮程序直接检查调用位置、调用次数和这项不等式。

这里**没有把行走误记为常数**：它的费用由初始组件 rank 与传播次数共同支付。

## 4. 搜索与方向转换为何与较小侧有关

先处理空侧：`split` 的两个端点比较直接返回，结构工作 `O(1)`。
两侧非空时记 `s=min(k,m-k)`，选中组件 rank 为 `r`。

双端 race 中，左侧只有在 `parent.key < value` 时继续上行；刚越过的左端
组件完全落在左输出中。右侧只有在 `value < parent.key` 时继续，刚越过的
右端组件完全落在右输出中。在较小输出对应的一端，这些组件包含至多 `s`
片叶，而 rank 为 `t` 的完整红黑组件至少有 `2^t` 片叶。沿 rib 的 rank
每两层至少增长一，所以较小端在 `O(log(s+1))` 步内停止。两端交错推进，
另一端不会比它多走超过常数步，选中组件满足

\[
r=O(\log(s+1)).
\]

`detach` 将选中组件转为向下表示，只经过其外侧路径。若被拆 connector 是根，
另一组件同 rank，转换也为 `O(r+1)`；否则需要 `expose` 的 inward sibling
与选中组件 rank 相等，同样为 `O(r+1)`。删除修复的初始 `r0≤r+O(1)`。

第 2 节保证分裂结果黑化后的 rank 至多 `r+1`，所以将这两个结果转换为
fingers 的工作为 `O(r+1)`。`join_fingers` 选择 rank 较小的树，从较大树
的 finger 只走到相同 rank 的黑节点；转换的两条组件路径也只有该 rank。
若走到大树的根，该根本身就满足这个 rank 界，不会突然转换一棵任意高的树。
根分支的 `join_down` 输入等 rank；非根分支的额外成本是一次插入修复。

因此所有方向转换、frame、大小/分隔键维护合计为 `O(r+1)`；可能很长的
删除传播与插入重着色另行支付，不隐藏在转换的常数里。

## 5. 混合序列使用同一个势能

使用逻辑孩子定义，而不是把反向 rib 指针误当作孩子：

\[
\Phi=\#\{\text{黑内部节点且两孩子黑}\}
       +2\#\{\text{黑内部节点且两孩子红}\}.
\]

外部叶贡献零；对所有 live lists 求和。该势能形式来自
[Tarjan–Van Wyk 1988 附录，第 172 页](https://www.ibr.cs.tu-bs.de/courses/ws2122/ag/Papers/Ch5/Tarjan-vanWyk_1988.pdf)。
下面的分支与记账对应当前代码，不以文献中的算法名称替代当前实现的论证。
证明过程中可将相同局部颜色权重延伸到暂时红红或短缺的逻辑森林；方向转换
本身不改变逻辑颜色关系，割下或接回一个 connector 只影响常数个局部权重。

### 插入重着色

`_repair_insert` 的可继续传播分支中，grand 原为黑且两孩子红，权重为 2；
parent 由红变黑但有一个红孩子，权重仍为 0；uncle 由红变黑且两孩子黑，
权重由 0 变 1；grand 变红，权重归零。三者合计 `ΔΦ=-1`。

若 grand 的上层 parent 是红色，边界权重为零，继续传播没有额外增量。
若上层 parent 为黑色，下一轮停止，其边界增量为常数。最终旋转、根黑化、
新叶与 connector 的创建也只改变常数个权重。这里 `I` 明确定义为可继续传播的
重着色轮数，即代码计数 `recolor_cascades`；它不是逐节点变色次数 `recolorings`，
一次传播可改变多个节点颜色。终止前最后一轮是否继续上行只影响常数项。
一次端插有 `ΔΦ≤C-I`，实际结构成本 `O(I+1)`，得到摊还 `O(1)`。
这里的常数来自固定数量局部节点，不从测试观测的最大值外推。

### 删除短缺传播与 split

可继续传播的分支中 parent、short、sibling 均黑，sibling 两孩子黑。
sibling 由黑变红失去权重 1，parent 的孩子从 BB 变成 BR 又失去权重 1，
故每个非终止传播 `ΔΦ=-2`。parent 为红时的终止分支及红兄弟/near/far
旋转只改变常数个权重，吸收入常数项。因而 `D+ΔΦ≤C`。

第 2 节给出整条组件拆分/join 路径只做 `O(r+1)` 个局部动作；它们可以增加
`O(r+1)` 势能。最终 `join_fingers` 的新 connector 有等 rank 黑孩子，
满足 `_repair_insert` 的相同局部前提，不要求它们是新叶。设其中上述传播轮数
为 `I`（同样对应 `recolor_cascades`），加上第 3 节明确支付的另一 rib 行走，可写为

\[
T_{split}\le C_1(r+D+I+1),\qquad
\Delta\Phi\le C_2(r+1)-D-I.
\]

用足够大的固定系数乘 `Φ`，即可支付传播和重着色，得到在操作契约下的

\[
\widehat T_{split}=O(\log(s+2)),\quad
\widehat T_{insert}=O(1),\quad T_{make},T_{adopt}=O(1).
\]

这个势能在 split 后继续保留；**没有重新从零开始一段纯插入序列**。
split 引入的新势能已在 split 的 `O(r+1)` 收费中支付。若从任意非空森林
开始，还必须计入初始势能。header/owner slots 至多两个、端点引用固定四个，
这些工作只加常数；不需要逐叶重绑。

有界检查在 12 条混合历史中逐次核对插入和删除传播的势能差，并实际执行
`split/adopt → 两侧继续端插 → 两侧再次 split/adopt → 再插入`。
势能的完整遍历只在探测器中进行，不进入生产操作。它不能用作排序计时。

## 6. 第二层列表势能与不能省略的前提

若上面的结构操作契约成立，可再取

\[
\Psi=c\sum_{L\ne\varnothing}(|L|-\log_2|L|).
\]

make/端插只增加常数；非空 split `m=a+b` 且 `a≤b` 时

\[
\Delta\Psi/c=\log_2\frac{a+b}{ab}\le1-\log_2 a.
\]

足够大的 `c` 可支付 `log(a+2)`；小 `a` 的剩余是常数，空侧 split 不改变
`Ψ`。两个势能非负，空森林初始化为零，故契约成立的 mixed 操作序列总结构
成本可收束为操作数的线性函数。共享核心的固定阶段、查询、必要阶段记录和
输出恢复另加 `O(n)`，而不是把完整审计、oracle 或 replay 算进这个界。

**仍需单独完成的算法层前提：** 对所有合法 Jordan 输入，Step 1/2 的最近
邻选择、奇数阶段的 `z1` 排除和两个修正如何保持下面的 gap/分组归纳性质：

| 实际调用 | 使用的必要前提 | 当前证据与尚需论证 |
| --- | --- | --- |
| 增向 Step 3(a) 在 A 的 RIGHT 端插；减向镜像 | 非 enclosing A 是指定 child group 的极端成员；新 pair 与 anchor 不交 | 源码通过指定端点查询和几何检查拒错；需证明所有合法前缀的边界选择均给出这种端点 |
| Step 3(b) 从另一边界 B 取得 source | source 与插入目标同 owner、不同 list；Step 3(a) 不改变 source 身份 | 已有显式转移计划和消费检查；需由 gap/分组不变量一般性推出，而非只依赖成功案例 |
| adopt 到新 parent | acquired 组在新 parent 内；保留组仍属旧 owner；不造成环 | 本地端点包含、slot 次序和待转移身份检查已实现；需结合既有子孙严格嵌套归纳说明不出现新环 |
| 同一迭代结束 | 没有 pending transfer/split；输出邻居和 family 对应 | `validate_iteration_complete` 强制 fence；一般合法性还需上述归纳性质恢复 |

每个完成前缀的几何外部模型、结构审计、同后端 replay 与有界穷举支持这些
前提，但不能代替一般证明。局部旋转在逻辑树上的红黑论证，还应与当前
反向指针、separator、`span` 和端点维护逐项核对，尤其是根角色变化。

所以本轮可以把逐段 join、根 rib 收费和混合势能从“仅有目标”推进到明确的
源码对应推导，但**不把条件性线性结构界写成已完成的无条件 Python 排序
最坏耗时保证**。`timing_ready=False` 保持不变；最终共同输入资格、实际
计时 pilot、协议冻结以及上述算法层前提尚需完成。

产生墙钟性能数据。上述各类证据不合并成独立样本数。
