# 正式实验之后的补充检查方案

本方案在第二次正式尝试及其主分析完成后制定。它不修改原协议，也不将两次尝试的比较追称为预登记分析。参数文件和脚本在构造微基准开始前提交固定。

## 仅构造的微基准

两组都直接构造 `HeterogeneousFingerBackend`，使用同一个预绑定的 `dict.__getitem__`、固定 `MINIMAL_POLICY`、`detailed_work=False`；只切换 `instrumented=True/False`。这比较的是旧计时配置中保留插桩但关闭详细计数的树，与无插桩树；不是开启详细计数的第三种配置。

事先完成 `prepare_uninstrumented()`。预热 5 个配对轮次，正式测量 50 个配对轮次，每组每批新建 256 个实例。偶数轮先插桩配置，奇数轮先无插桩配置；正式阶段重新从偶数轮开始，两组各有 25 次先执行。

计时覆盖构造函数调用、循环和向预分配列表写入对象。对象一直保留到计时结束，以免把析构和引用环回收误算为单次创建。主动 `gc.collect()`、对象检查和清理在计时外；自动 GC 保持启用，阈值为 700/10/10，可能在计时内发生，保存其计数变化。保留对象的批量设计会影响自动 GC 和内存行为，所以结果不是完整排序中构造部分的精确分解，也不是 54 个方法绑定的独立成本。

每批前后核对并保存电源。使用同一台机器、原 Python 路径和版本，核对冻结的 151 个源码文件与正式环境。没有测试性试跑、自动校准、异常值剔除或因结果改变参数。发生错误时保留已写入记录并停止。不会调用排序入口或树更新/查询操作。

保留 110 条原始批次记录（10 条预热，100 条测量）。报告每批时长除以 256 后的 50 个观测的中位数、R7 四分位数/IQR 和范围，以及配对轮次的差值和比值。不扣除计时器或空循环基线，不从正式排序时间扣除本次构造观测，不据此重跑正式采样。

## 两次尝试的事后描述性比较

只纳入首次完整完成的 common 140、targeted_split 12、structural 18 个输入，共 170 个；名单由完成来源确定，不按结果挑选。首次 geometric 的部分 PASS 输入不纳入。

两次档案先分别独立验证，再从原始 20 个正式批次重新计算每输入 tree/list 比值。逐项核对 case、输入摘要和公共 B 一致；保存两次各后端中位数、两次比值、比值差 `r2-r1`、相对变化 `100*(r2/r1-1)` 和方向转换。按来源和整体报告比值范围、中位数、绝对相对变化及方向转换数。

这是作者在看过第二次主结果后要求的、**不在原协议内的事后补充**。只描述这两次固定会话的稳定程度；不将它们当作独立重复，不估计总体稳定概率，不做显著性检验、置信区间或因果解释。第一次的电源失败和第二次重启偏离继续披露。两次时间不合并，不改变第二次 302 输入的主要统计。
